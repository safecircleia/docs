SafeCircle es un conjunto de servicios pequeños que comparten un mismo backend. Esta sección explica cómo se conectan, qué partes de la API puedes consultar y cómo viajan los datos desde el teléfono de un menor hasta la pantalla de un padre o madre.

<Callout type="warn" title="Aún no hay programa público para desarrolladores">
  SafeCircle está en beta privada. La API que se describe aquí es la que usan las propias apps de SafeCircle. **No tiene versiones, no hay garantía de estabilidad y no existen claves de API públicas**. Los procedimientos y campos pueden cambiar entre versiones. Si quieres construir sobre ella, escribe antes a **support@safecircle.tech**.
</Callout>

## Mapa de la plataforma

```text
 Teléfono del menor                          Padre o madre
 ┌───────────────────┐                       ┌───────────────────────┐
 │ App del menor     │                       │ Panel (web)           │
 │ (Android)         │                       │ App para padres       │
 │ modelo de IA local│                       │ (Android)             │
 └─────────┬─────────┘                       └──────────┬────────────┘
           │ x-device-token                             │ cookie de sesión
           │                                            │ o token bearer
           ▼                                            ▼
        ┌───────────────────────────────────────────────────────┐
        │ Backend  (Hono + tRPC en Cloudflare Workers)          │
        │ api.safecircle.tech                                   │
        └───┬──────────────┬──────────────┬──────────────┬──────┘
            │              │              │              │
            ▼              ▼              ▼              ▼
      PostgreSQL      D1 (métricas)  R2 (imágenes,   Push (FCM)
      (Hyperdrive)                   comentarios)
            ▲
            │ clave del bot          enlace familiar firmado
   ┌────────┴─────────┐              ┌───────────────────────┐
   │ Bot de Telegram  │              │ Buscador              │
   │ @safecirclehq_bot│              │ search.safecircle.tech│
   └──────────────────┘              └───────────────────────┘
```

| Componente | Qué hace | Habla con |
|---|---|---|
| **App del menor** (Android) | Observa el texto visible con un Servicio de accesibilidad y lo clasifica **en el dispositivo**. Solo envía una alerta cuando detecta riesgo. | Backend, con un token de dispositivo |
| **Panel para padres** (web) | Alertas, analíticas, hijos, dispositivos y ajustes. | Backend, con una cookie de sesión |
| **App para padres** (Android) | Alertas móviles, notificaciones push y vinculación. | Backend, con un token bearer de sesión |
| **Backend** | Autenticación, datos, alertas, push, imágenes y telemetría. | PostgreSQL, D1, R2, FCM |
| **Bot de Telegram** | Vincula una cuenta de Telegram y muestra cuenta, hijos y alertas bajo demanda. | Backend, con una clave de bot |
| **Buscador** | Metabuscador que prioriza la privacidad, con bloqueo opcional de búsqueda segura familiar. | Backend (ajustes y enlaces familiares) |
| **Modelo de IA** | Clasifica las conversaciones en el dispositivo del menor. | Se ejecuta dentro de la app del menor |
