SafeCircle is a set of small services that share one backend. This section explains how they connect, which parts of the API you can read about, and how data moves from a child's phone to a parent's screen.

<Callout type="warn" title="No public developer program yet">
  SafeCircle is in beta. The API described here is the one SafeCircle's own apps use. It is **not versioned, not covered by a stability guarantee, and there are no public API keys**. Procedures and fields can change between releases. If you want to build on it, write to **support@safecircle.tech** first.
</Callout>

## Platform map

```text
 Child's phone                               Parent
 ┌───────────────────┐                       ┌───────────────────────┐
 │ Child app         │                       │ Dashboard (web)       │
 │ (Android)         │                       │ Parent app (Android)  │
 │ on-device AI model│                       └──────────┬────────────┘
 └─────────┬─────────┘                                  │ session cookie
           │ x-device-token                             │ or bearer token
           ▼                                            ▼
        ┌───────────────────────────────────────────────────────┐
        │ Backend  (Hono + tRPC on Cloudflare Workers)          │
        │ api.safecircle.tech                                   │
        └───┬──────────────┬──────────────┬──────────────┬──────┘
            │              │              │              │
            ▼              ▼              ▼              ▼
      PostgreSQL      D1 (metrics)   R2 (images,     Push (FCM)
      (Hyperdrive)                   feedback)
            ▲
            │ bot API key            signed family link
   ┌────────┴─────────┐              ┌───────────────────────┐
   │ Telegram bot     │              │ Search                │
   │ @safecirclehq_bot│              │ search.safecircle.tech│
   └──────────────────┘              └───────────────────────┘
```

| Component | What it does | Talks to |
|---|---|---|
| **Child app** (Android) | Watches visible text with an Accessibility Service and classifies it **on the device**. Sends an alert only when risk is detected. | Backend, with a device token |
| **Parent dashboard** (web) | Alerts, analytics, children, devices, settings. | Backend, with a session cookie |
| **Parent app** (Android) | Mobile alerts, push notifications, pairing. | Backend, with a session bearer token |
| **Backend** | Auth, data, alerts, push, media, telemetry. | PostgreSQL, D1, R2, FCM |
| **Telegram bot** | Links a Telegram account and shows account, children and alerts on demand. | Backend, with a bot key |
| **Search** | Privacy-first metasearch, with optional family safe-search lock. | Backend (settings and family links) |
| **AI model** | Classifies conversations on the child's device. | Runs inside the child app |
