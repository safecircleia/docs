SafeCircle's code lives in the `safecircleia` GitHub organisation. Only some repositories are public today, so only those are linked.

| Repository | Purpose | Stack | Licence | Visibility |
|---|---|---|---|---|

| `android-child` | Child app: on-device detection and pairing | Kotlin, Jetpack Compose, Hilt, Ktor, ONNX Runtime | MIT | Private |

| `telegram-bot` | `@safecirclehq_bot`. See [Telegram bot](/en/docs/developers/telegram-bot) | Bun, grammY, Cloudflare D1 | Not published | Private |
| `observability` | Prometheus and Grafana stack. See [Observability](/en/docs/developers/observability) | Docker Compose, Prometheus, Grafana | Not published | Private |

## Conventions across repositories

- **Package manager and runtime:** Bun for the TypeScript projects.
- **Hosting:** Cloudflare Workers for the backend, the dashboard and Search.
- **Commits:** Conventional Commits (`feat:`, `fix:`, `chore:`).
- **Languages:** the dashboard and Search ship in English and Spanish, with a test that keeps both key sets identical.
- **Type safety:** Zod validates every input at the API boundary, and the schema is the single source for database types.

## Contributing

There is no public contribution process for the private repositories. If you want to report a problem, use **More › Report a bug** in the dashboard, or write to **support@safecircle.tech**. For the public repositories, follow the guidance in each repository's README and licence.
