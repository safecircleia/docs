La app del menor solo lee la pantalla de estas cinco apps. Lo garantiza Android: el Servicio de accesibilidad está registrado para estas apps y ninguna más.

| App | Nombre de paquete |
|---|---|
| WhatsApp | `com.whatsapp` |
| Instagram | `com.instagram.android` |
| Telegram | `org.telegram.messenger` |
| Snapchat | `com.snapchat.android` |
| TikTok | `com.zhiliaoapp.musically` |

Cualquier app que no esté en esta lista no se supervisa, aunque sea de mensajería.

## Qué significa para ti

- El nombre de la app que aparece en una alerta se obtiene del nombre de paquete de arriba.
- La detección solo funciona mientras el menor tiene abierta en pantalla una de estas apps.
- Cada app se analiza como máximo una vez cada 5 minutos. Consulta [Cómo funciona la app del menor](/es/docs/platform/android/how-it-works).
- Solo se cubren las versiones de Android de estas apps. No hay app del menor para iOS — consulta [iOS](/es/docs/platform/ios/overview).

<Callout type="info">
  La lista está fijada en la app y no se puede cambiar desde el panel. Si necesitas que se cubra otra app, cuéntanoslo con **Más › Pedir una función** en el panel o en **support@safecircle.tech**.
</Callout>
